# 014 OpenFOAM channel benchmark evidence

Generated by `backend/.venv/bin/python scripts/qualification/014/run_benchmark.py --prefix <OpenFOAM v2412 prefix>`. The script hashes both local executables, runs `blockMesh` and `icoFoam` through the BLUECAD registry, and writes the JSON, complete case archive, and captured parser fixtures in `scripts/qualification/014/`. The JSON is generated output, not an edited target value.

This is a two-dimensional, laminar, incompressible channel with no-slip walls, uniform velocity inlet, zero kinematic-pressure outlet, and an empty front/back boundary. Height is 0.01 m, length is 0.2 m, mean inlet velocity is 0.01 m/s, kinematic viscosity is 1e-6 m²/s, and Reynolds number is 100. The structured mesh is 160 × 24 × 1 cells. Pressure is sampled at x = 0.05 and 0.15 m on the centreline. The analytic fully developed plane-Poiseuille comparison is Δp = 12ρνUΔx/H² and centreline velocity = 1.5U. The reference density, 1000 kg/m³, converts OpenFOAM's kinematic pressure to Pa for this benchmark comparison only; the adapter itself reports kinematic pressure drop (m²/s²) because density is not a case input.

The generated JSON records the actual residual, measured pressure drop and centreline velocity, analytic values, relative errors, exact binary hashes, and log hashes. This is one benchmark point at the recorded inputs, mesh, and solver settings; it does not establish qualification across the supported case family. It does not qualify turbulent flow, other geometries, wall roughness, other fluids/densities, transient accuracy, mesh independence, or a general CFD validity envelope. Numerical convergence alone does not set `validity` or `qualification_record_ref` on adapter results.
