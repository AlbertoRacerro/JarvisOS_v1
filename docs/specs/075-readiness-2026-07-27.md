## Required delivery gates

The implementation PR may merge only when:

- the registry has moved through `in_progress` and `in_review` correctly;
- canonical 047 fixtures match output keys, units, every numeric `float.hex()`,
  diagnostics, canonical `result.json` bytes, and SHA-256;
- equivalent-unit tests remain separate from historical 047 request semantics;
- the bundled-only runner boundary is not widened;
- schema-v1 and FLOWSHEET-1 regression suites remain green;
- full backend CI and required real-runner proofs are terminal green;
- an independent reviewer approves or adds at least one negative graph or
  profile-identity test;
- no unresolved P1/P2 review thread remains.

## Rollback boundary

If exact 047 identity or bundled runner authority cannot be preserved, disable
or remove only the new 075 profile, retain failed evidence, preserve all existing
047 registrations and artifacts, and return 075 to `planned` or `blocked`.
