## Fresh evidence

The accepted 128 AE002 contract requires generic HTTP clients/provider SDK aliases not to bypass architecture enforcement. Fresh inspection of `scripts/check_architecture_enforcement.py` confirms the live scanner only recognizes `httpx`/`requests` request verbs plus provider-import `.complete()` calls. ## Frozen design

- Extend the existing AST classifier; do not create another network-policy implementation.
- Reuse import alias normalization.
- Add a small deterministic same-file constructor-binding map only where needed to recognize `urllib3.PoolManager`, `socket.socket`, `aiohttp.ClientSession`, and `http.client.HTTPConnection` / `HTTPSConnection` instance calls.
- Match only concrete frozen network methods/types, not generic `.request` or `.connect` method names.
- Cover `urllib.request.urlopen`, `urllib3` request dispatch, `socket.create_connection` plus socket-instance connect/connect_ex, aiohttp session request verbs, `websockets.connect`, and http.client connection request/connect.
- Preserve current accepted-owner and exact-exception behavior.
- Dynamic/interprocedural dispatch not resolved by this bounded static pattern set remains residual risk rather than justification for a taint framework.
