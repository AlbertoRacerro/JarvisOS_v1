## Scope decision

1. make the Memory/Development/Coding workspace header and following work area structurally stack as a compact top header plus full work area;
2. make peer/subpage navigation neutral when inactive and soft-accent/outlined when active across Design, Memory/Development/Coding and Settings;
3. preserve the strong solid green treatment for genuine primary actions rather than ordinary peer navigation;
4. add deterministic regression coverage and exact-head browser proof.

A wrapper around header+surface is acceptable if it is the smallest robust way to prevent the shell flex row from treating them as peer columns. A CSS-only fix is acceptable only if it deterministically establishes the same structural result without relying on fragile viewport coincidence.
